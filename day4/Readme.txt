-------------------------------------------
Project Description
-------------------------------------------

This application is a console-based Internship
Management System developed using Object-Oriented
Programming in Python.

The system helps manage interns, assign tasks,
track progress, calculate performance scores,
and store records permanently using file handling.

-------------------------------------------
Features
-------------------------------------------

1. Register New Intern
2. Automatically Generate Unique Intern ID
3. Prevent Duplicate Registration
4. Assign Multiple Tasks
5. Update Task Status
6. Search Intern by Name or ID
7. View Pending Tasks
8. View Completed Tasks
9. Calculate Performance Score
10. Display Gold, Silver, and Bronze Rankings
11. Show Top Performing Intern
12. Save Records to File
13. Automatically Load Records on Startup
14. Console Dashboard Menu

-------------------------------------------
Performance Scoring
-------------------------------------------

Completed Task = 10 Points

In Progress = 5 Points

Pending = 0 Points

-------------------------------------------
Ranking System
-------------------------------------------

Gold Intern:
80 points or above

Silver Intern:
40 to 79 points

Bronze Intern:
Below 40 points

-------------------------------------------
How to Run
-------------------------------------------

1. Open the project folder in Visual Studio Code.

2. Open a terminal.

3. Run the following command:

python main.py

or

python3 main.py

depending on your Python installation.

-------------------------------------------
Notes
-------------------------------------------

• Data is automatically loaded from data.txt when the program starts.

• Records are automatically saved when you choose Save Data or Exit.

• Duplicate interns are prevented using Email or CNIC.

• Every intern receives a unique ID.
